Verdict per model output: 1 good · 2 acceptable · 3 bad · 0 clear. Keys apply to the highlighted output, then move to the next one (and to the next tile after the last). ↑/↓ change the highlighted output · ←/→ tile · n / Shift+N next / previous specimen · g 5 / 1 generations · d next draw (1 generation) · b blind. A tile counts as reviewed when every model currently shown has a verdict. Verdicts are kept in this browser only; use export verdicts to save a JSON file and send it back.
Blind shuffles the VS outputs per tile and hides model names and LPIPS; verdicts are still stored under the true model. LPIPS (AlexNet, vs C&SF; lower = closer) is shown for context only and is not the verdict. Each VS output comes from the fold in which this tile was held out. Draws are independent samples (seeds 1234–1238); generations sets how many are shown per model (one row per model), or set it to 1 to compare one chosen draw side by side.
